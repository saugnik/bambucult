# Node: custom wordmark

Node is a typography-led identity in which "BambuCult" is set in Libre Caslon Text (the family of the site's own headlines) and redrawn as outlines, so the logo needs no web font. The capital B is cut as a bamboo culm, its stem split by two nodes whose ends flare like Caslon's own bracketed serifs, and it is drawn in a custom semibold (interpolated between Caslon Text Regular and Bold) in culm brown, so the initial is the mark and the lockup never has to repeat a B beside the name. The B carries the idea alone: the rest of the word, including the l of Cult, is left as calm, carefully spaced Caslon (tracked −12, with b–u, u–C and C–u kerned), so the word reads like a well-set catalogue masthead rather than a gimmick and sits naturally beside the site's Caslon headlines and Plex body text. The B's top and bottom serifs are bracketed with the same concave curve as its node flares, so the whole letter looks drawn by one hand. The favicon is a separate cut of the same B fitted to the 32-pixel grid, with its cap line, baseline, stem edges and both node gaps on whole pixels at 32 px and again at 16 px, and the one-colour version works for stamps, invoices and laser-engraving on the products (Libre Caslon is SIL OFL, so outlining and modifying it for a logo is permitted).

Review changes: the third node on the l of Cult was removed because its gap sat on the x-height and made the l read as a tall i at 24–32 px ("BambuCuit"); the B's straight wedge serifs were bracketed to match its flares; the favicon's node gaps were widened from 1.5 px to whole pixel rows at 32 px; and all standalone files now carry fixed colours, with logo-inline.svg the only version that uses currentColor and --bc-accent.

Rename (BambooCult → BambuCult): the "oo" was replaced by a single u taken from the same Libre Caslon Text outlines at the same optical size, and the whole word was re-spaced. The culm B is unchanged — the same drawing, byte for byte. Only the three pairs that the new letter touches carry a kern: b–u −4, u–C −14, C–u −34 (the C–u value is inherited from the old setting), chosen so the optical gaps through b-u-C-u match the rest of the word rather than the raw sidebearings. The lockup is now viewBox 0 0 516.33 84, an aspect of 6.15 : 1, down from 6.9 : 1; the mark and the favicon are untouched because the B is untouched.
